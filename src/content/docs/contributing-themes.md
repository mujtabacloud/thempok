## Theme Quality Guidelines

To ensure high quality and safety for all developers downloading Thempok themes, all submissions must meet these principles:

- **Open Source License:** MIT, Apache 2.0, or BSD-3-Clause license.
- **Zero Tracking or Ads:** No third-party trackers, telemetries, or crypto miners.
- **Performance:** Minimum 90+ score on Google Lighthouse across all categories.
- **Accessibility:** Semantic HTML, appropriate ARIA attributes, and accessible color contrast.

## Submission Checklist

- [ ] Working live demo deployed on a public URL.
- [ ] Public GitHub repository with clear README instructions.
- [ ] Light and Dark mode support verified.
- [ ] Clean codebase with minimal external dependencies.

## How to Submit

Open a Pull Request or create an Issue on the [Thempok GitHub repository](https://github.com/thempok/thempok) with your theme details, demo URL, and repository link.
